Excited to share my latest Full-Stack project: Smart Campus – A Placement Management Portal! 🎓💼
Over the past few days, I’ve been building a comprehensive solution to streamline the campus recruitment process for both students and Training & Placement Officers (TPOs). Managing recruitment drives, eligibility, and student data can be complex, so I built this portal to make it seamless and automated.
Key Features of the Portal: ✅ Student Dashboard: Real-time access to available recruitment drives, one-click application, and automated eligibility checking based on CGPA and department. ✅ Admin (TPO) Panel: Powerful management tools to post new job drives, view the entire batch in a "Student 360" view, and access uploaded resumes. ✅ Eligibility Engine: An automated logic system that filters eligible candidates for specific drives instantly. ✅ Data Export: Integrated NAAC-ready Excel export functionality for simplified administrative reporting. ✅ Security: Robust authentication system with JWT and password encryption using Bcrypt.
🛠️ Tech Stack:
Frontend: React.js (Hooks, Router)
Backend: Node.js, Express.js
Database: MongoDB (Mongoose)
Styling: Custom CSS with Glassmorphism effects and Inter/Times New Roman typography.
Tools: Multer (File Uploads), XLSX (Data Export), Axios (API handling).
Building this helped me dive deep into state persistence, managing complex database relationships, and creating a responsive, professional UI/UX.
